# PowerPoint to Markdown to PowerPoint

Extract presentation text into an editable Markdown file, refine it with an AI agent or your favorite editor, then convert it back into a PowerPoint presentation.

## Features
- Export slide text to Markdown
- Edit content in a simple, agent-friendly format
- Rebuild a PowerPoint from the edited Markdown

## Limitations
This tool focuses on text; layout, formatting, and other PowerPoint elements may not be preserved exactly.
